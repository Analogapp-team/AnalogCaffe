
What are Hooks 

A hook in React is a special function that lets you "hook into" React's state and lifecycle features 
from function components. Unlike class components that use lifecycle methods like componentDidMount, 
hooks allow function components to manage state (useState), perform side effects (useEffect), 
access context (useContext), create references (useRef), and more. Introduced in React 16.8, hooks enable function 
components to have the same capabilities as class components while providing cleaner, more reusable code patterns. 
They follow a strict rule: hooks must be called at the top level of React functions and cannot be used conditionally or in loops, 
ensuring consistent behavior across renders.


useAuth() - Authentication Hook

What is useAuth()?
useAuth() is a custom React hook that provides easy access to the authentication context throughout the application. 
It's a convenience wrapper around React's useContext hook specifically for authentication.


isAuthenticated - Authentication State Variable
What is isAuthenticated?
isAuthenticated is a boolean value derived from the authentication context that indicates whether 
a user is currently logged into the application.

Behind the Scenes Flow:
1. App loads → AuthProvider mounts
2. useEffect runs → Parse.User.currentAsync() checks localStorage
3. If token exists → Parse SDK validates with server
4. Server responds with user data → setCurrentUser(user)
5. isAuthenticated = !!user → becomes true
6. All components using useAuth() re-render with new value

Database Structure (Parse Classes = Tables)
Tables are created automatically via Parse's schema-on-write:

First write operation creates the table
Columns are dynamic - created when you first set data

Common classes used:
_User (built-in) - User authentication & profiles
Event - Custom class for events
Post - Custom class for social posts


// First time saving an Event creates the "Event" table
const Event = Parse.Object.extend("Event");  // References/creates class
const event = new Event();                   // Creates instance
event.set("title", "My Event");              // Creates "title" column
event.set("participants", []);               // Creates "participants" column
await event.save();                          // Table created if doesn't exist

Service Layer Architecture
Each domain has a dedicated service file:

UserService.js - Manages _User table

// Built-in User class (special permissions)
const q = new Parse.Query(Parse.User);  // Query _User table
const user = await q.get(userId);       // Fetch user by ID

Special characteristics:
_User table is built-in
Authentication handled automatically
ACL (Access Control) for security



Data Relationships
Pointer Relationships (Foreign Keys)

// In PostService.js - Creating a relationship
post.set("user", currentUser);  // currentUser is Parse.User object

// In queries - Include related data
query.include("user");  // Fetches full user object, not just pointer
